## ⚡ Ключевой функционал

### 1. ⏱ Модуль активной тренировки и таймер отдыха (FR-1)
- **Калькулятор веса**: быстрые кнопки инкремента `+1`, `+2.5`, `+5`, `+10`, `+20` кг, плюс цифровая клавиатура с кнопками очистки/удаления.
- **Слайдер RIR (Reps in Reserve)**: дискретный ползунок 0..5+ с цветовой подсветкой запаса сил.
- **Таймер отдыха**: автоматический обратный отсчет после каждого сета (90 сек между сетами, 180 сек между упражнениями), звуковой сигнал и вибрация.
- **Быстрый ввод**: сохранение сета в пределах $\le 4$ нажатий; зоны нажатия $\ge 48\times 48\text{ dp/px}$.

### 2. 📅 Календарь, клонирование и автоподстановка (FR-2)
- Месячный и недельный вид с цветовой индикацией статуса тренировок (зеленый — завершена, желтый — черновик, обводка — сегодня).
- **Клонирование сессий**: перенос структуры упражнений, подходов и весов из любой исторической тренировки в выбранный день.
- **Автоподстановка**: автоматическое заполнение целевого веса и повторений из последнего завершенного подхода в истории.

### 3. 🧠 Детерминированная прогрессия нагрузок (FR-3, No-AI)
Математический расчет целевого веса следующей тренировки без внешних серверов и нейросетей:
$$W_{next} = W_{prev} \times (1 + \Delta)$$
- **$RIR \in [0, 1]$** (высокая интенсивность): максимальная прогрессия $\Delta = +0.05$ (+5%).
- **$RIR \ge 2$** (умеренная нагрузка): консервативный шаг $\Delta = +0.02$ (+2%) либо рекомендация увеличить число повторений.
- **План не выполнен**: удержание веса ($\Delta = 0.0$) или deload.
- Автоматическое квантование до шага инвентаря ($1.25$ или $2.5$ кг).

### 4. 📊 Аналитика и экспорт данных (FR-4)
- **Двухосевые графики**: динамика расчетного 1RM (формулы Эпли и Бжицки) и максимального рабочего веса во времени.
- **Экспорт в Excel (.xlsx)**: генерация таблиц тренировок и подходов с русскими заголовками.
- **Экспорт в PDF**: генерация сводного отчета формата A4 за выбранный период со статистикой тоннажа.

## 🛠 Технологический стек

### Android Приложение (`app/`)
- **Язык**: Kotlin 2.3.20, Java 17
- **UI**: Jetpack Compose, Material 3, Canvas Graphics
- **БД**: Room 2.7 (SQLite, Local-First)
- **Архитектура**: Clean Architecture + MVVM + MVI unidirectional Flow
- **Экспорт**: Android `PdfDocument`, Streaming OpenXML ZIP writer

### Web-версия (`web/`, `docs/`)
- **Стек**: React 19, TypeScript, Vite 8, Tailwind CSS v4, Lucide Icons
- **Экспорт**: SheetJS (XLSX), jsPDF, autoTable
- **Звук/Вибро**: Web Audio API Oscillator + Navigator Vibration API
- **Хранилище**: Local-First Database с библиотекой упражнений

## 💻 Локальный запуск и сборка

### Сборка Android приложения
```bash
# Установка переменной JAVA_HOME (JDK 17)
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr

# Запуск тестов
./gradlew testDebugUnitTest

# Сборка APK
./gradlew assembleDebug
# Готовый файл: app/build/outputs/apk/debug/app-debug.apk
```

### Запуск Web-версии для разработки
```bash
cd web
npm install
npm run dev
# Откроется локальный сервер http://localhost:5173
```
