# Original User Request

## Initial Request — 2026-08-19T18:27:11Z

Создать production-ready мобильное приложение «Трекер Тренировок» для учёта силовых тренировок. Основная платформа: Android. Приложение должно быть лёгким, быстрым и без лишнего раздувания. Работает полностью офлайн (local-first архитектура, без внешних API и нейросетей), использует детерминированные алгоритмические формулы для прогрессии нагрузок, включает календарь, графики аналитики и экспорт данных (Excel/PDF).

Весь интерфейс приложения должен быть на русском языке.

Working directory: ~/teamwork_projects/workout_tracker
Integrity mode: development

## Требования

### R1. Активная тренировка и ввод данных
Приложение должно поддерживать фиксацию отдельных подходов во время активной тренировки. Ввод веса осуществляется кнопками инкремента (+1, +2.5, +5, +10, +20 кг) плюс прямой цифровой ввод с кнопками очистки/удаления последнего разряда. Количество повторений вводится как целое положительное число. RIR (повторения в запасе до отказа, 0–5) выставляется дискретным ползунком с шагом 1. После сохранения подхода автоматически запускается настраиваемый таймер отдыха (по умолчанию: 90 сек между подходами, 180 сек между упражнениями) с фоновым уведомлением/вибрацией по окончании. Зоны нажатия должны быть ≥48×48 dp. Фиксация одного подхода должна укладываться максимум в 3 экрана / 4 нажатия.

### R2. Календарь, клонирование сессий и автоподстановка
Календарный интерфейс (месяц/неделя) с цветовой индикацией выполненных тренировок. Пользователь может клонировать любую историческую тренировку в новый день — переносятся все упражнения, порядок и количество подходов. При добавлении упражнения в текущую тренировку приложение автоматически подставляет целевой вес и повторения из последнего завершённого подхода этого упражнения в истории.

### R3. Алгоритмический модуль прогрессии нагрузок (детерминированный, без ИИ)
Формула прогрессии: W_next = W_prev × (1 + Δ), где:
- RIR ∈ [0, 1] и плановые повторения выполнены → Δ = 0.05
- RIR ≥ 2 → Δ = 0.02 (или удержание веса с рекомендацией увеличить повторения)
- Плановые повторения не выполнены → W_next = W_prev (удержание) или шаг снижения (deload)

Результат округляется до ближайшего настраиваемого шага инвентаря (например, 1.25 или 2.5 кг). У каждого упражнения есть ProgressConfig (min_step_kg, progression_percent). Рекомендованный вес отображается как подсказка-placeholder; пользователь может перезаписать его.

### R4. Аналитика и экспорт
Графики прогресса по упражнению: ось X = дата, ось Y1 = расчётный 1RM (формула Эпли/Бжицки), ось Y2 = рабочий вес. Экспорт всех сессий/упражнений/подходов в .xlsx и генерация сводного PDF-отчёта за выбранный период. Вся обработка локальная, сеть не требуется.

## Критерии приёмки

### Эффективность ввода тренировки
- [ ] Пользователь может выставить вес кнопками +X и RIR ползунком менее чем за 5 секунд (по количеству нажатий, не по реальному времени)
- [ ] Все интерактивные зоны нажатия ≥ 48×48 dp
- [ ] Фиксация подхода (вес + повторения + RIR + подтверждение) требует максимум 3 экрана / 4 нажатия

### Клонирование сессий и автоподстановка
- [ ] Клонирование прошлой тренировки в новый день копирует все упражнения с порядком и количеством подходов
- [ ] Автоподставленные значения веса/повторений соответствуют последнему завершённому подходу каждого упражнения
- [ ] Если истории упражнения нет, поля остаются пустыми (без краша, без ошибки)

### Корректность алгоритма прогрессии
- [ ] Юнит-тесты покрывают все три ветки Δ: RIR 0–1 → 0.05, RIR ≥2 → 0.02, невыполнение плана → удержание
- [ ] Округление до шага инвентаря корректно (например, 52.6 кг при шаге 2.5 → 52.5 кг)
- [ ] Алгоритм работает полностью офлайн — без сетевых вызовов
- [ ] Пользователь может перезаписать рекомендованный вес

### Целостность экспорта
- [ ] Сгенерированный .xlsx открывается без ошибок в стандартном табличном приложении и содержит корректные данные
- [ ] Сгенерированный .pdf открывается без ошибок в стандартном PDF-просмотрщике и содержит корректные данные
- [ ] Экспорт корректно охватывает выбранный пользователем период без пропущенных сессий

### Таймер отдыха
- [ ] Таймер запускается автоматически после сохранения подхода
- [ ] Таймер выдаёт фоновое уведомление/вибрацию при достижении нуля
- [ ] Интервалы по умолчанию: 90 сек (между подходами) и 180 сек (между упражнениями), оба настраиваемые

### Качество приложения
- [ ] Приложение собирается и запускается на Android без крашей
- [ ] Навигация между экранами отзывчивая (без заметных задержек на среднем устройстве)
- [ ] Все данные сохраняются между перезапусками приложения (локальная БД)
- [ ] Весь пользовательский интерфейс на русском языке

## План верификации

### Программная (автоматическая)
- Юнит-тесты алгоритма прогрессии: все ветки Δ, округление, крайние случаи (0 кг, 0 повторений)
- Юнит-тесты логики клонирования сессий: все упражнения скопированы, правильная автоподстановка веса, крайний случай пустой истории
- Верификация сборки: проект компилируется и создаёт запускаемый APK/bundle без ошибок

### Agent-as-Judge (по рубрике)
- Ревью UI: подтвердить зоны нажатия ≥ 48dp, подтвердить ввод подхода ≤ 4 нажатий / 3 экрана
- Ревью экспорта: открыть .xlsx и .pdf, проверить точность данных относительно исходных записей
- Ревью таймера: проверить автозапуск, срабатывание уведомления, настраиваемые интервалы
